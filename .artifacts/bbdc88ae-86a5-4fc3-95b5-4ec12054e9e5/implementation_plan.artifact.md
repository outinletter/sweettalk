# 실시간 날씨 및 지역 특색 반영 기능 구현 계획

사용자가 설정한 위치 정보를 바탕으로 실시간 날씨 정보를 가져오고, AI가 해당 지역의 특성(랜드마크, 분위기 등)을 대화에 반영하도록 개선합니다.

## User Review Required

> [!IMPORTANT]
> 날씨 정보는 `wttr.in` 오픈 API를 사용합니다. 별도의 API 키는 필요 없으나, 네트워크 연결 상태에 따라 정보를 가져오지 못할 경우 기본 문구(날씨 정보 없음)로 대체됩니다.

## Proposed Changes

### [SweetTalkAPI]

#### [MODIFY] [App.tsx](file:///D:/Data/Project/SweetTalkAPI/src/App.tsx)
- **날씨 조회 유틸리티 추가**: `wttr.in` API를 사용하여 텍스트 기반 날씨 정보(기온, 상태)를 가져오는 `fetchWeather` 함수를 작성합니다.
- **`buildSystem` 함수 개선**:
    - `weather` 파라미터를 추가합니다.
    - 프롬프트에 "사용자의 위치와 날씨, 그리고 해당 지역의 알려진 특징(랜드마크 등)을 대화에 자연스럽게 포함하라"는 지침을 강화합니다.
- **`Chat` 컴포넌트 수정**:
    - `weather` 상태(state)를 추가합니다.
    - `useEffect`를 통해 컴포넌트 마운트 시 및 `location` 변경 시 날씨를 조회합니다.
    - AI 응답 생성 시(`genReply`) 현재 저장된 `weather` 정보를 `buildSystem`에 전달합니다.

## Verification Plan

### Manual Verification
- **설정 확인**: 환경설정에서 위치를 "서울 강남구" 또는 "제주도"로 설정합니다.
- **대화 테스트**:
    - "안녕"이라고 보냈을 때 AI가 현재 날씨(예: "오늘 서울은 좀 흐리네")를 언급하는지 확인합니다.
    - 지역 특색(예: "제주도 바다 냄새 좋겠다")이 대화에 섞여 나오는지 확인합니다.
- **오프라인 테스트**: 네트워크 연결이 없을 때 오류 없이 기본 대화가 진행되는지 확인합니다.
