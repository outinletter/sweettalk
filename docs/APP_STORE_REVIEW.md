# SweetTalk 언어 지원 및 심사 보완

2026-10-15

## 반영 내용
- 최초 동의 화면과 시작 화면의 환경설정에서 한국어·영어·일본어·중국어 간체 선택. 대화 설정에서도 변경 가능. 선택은 기기에 저장.
- 화면·설정·캐릭터 선택·동의 안내·개인정보 정책·약관에 선택 언어 반영. 기존 대화 원문은 유지하고 새 응답에 선택 언어 적용.
- 영어 응답에는 한국어 번역, 다른 언어 응답에는 영어 번역. 대체 표현 1가지. 번역 캐시는 언어별로 분리.
- 번역 옆에서 표현 저장. 환경설정에서 번역을 가리고 확인하며 복습. 표현집이 새 백업 형식(version 2)에 포함되며 이전 배열 형식도 복원 가능.
- 이용 기준 18세 이상으로 정합화. 변경된 데이터 전송·안전 검사 안내에 기존 사용자도 다시 동의.
- 날씨 기능은 기본 해제. 별도로 활성화하고 AI 전송에 동의한 경우에만 입력 지역 전송. 해제하면 새 대화 맥락에서 위치·날씨 제외.
- DeepSeek로 입력과 출력에 독립적인 안전 평가 요청. 부적절하다고 판단된 요청·응답은 거절. 검사 실패·잘못된 응답은 표시하지 않음. 응답 생성 요청과 별도의 검사이나 동일 제공자를 사용하므로 모델 오판 가능성을 없애지는 못함.
- 신고 작성·복사·운영자 이메일·메일 앱 미설치 시 웹메일 문의 경로 안내. 자동 발송하지 않음.
- 모든 기기 데이터 삭제 및 예약 알림 취소. 선택 언어만 유지. 외부 처리 데이터와 별도 백업은 함께 삭제되지 않음.
- 4개 언어 스토어 설명을 실제 기능·AI 연인형 경험·18세 이용 기준과 일치시킴.

## 검증
- TypeScript 및 Vite 프로덕션 빌드 통과.
- 아이폰용 서명 빌드 통과.
- 서버 모의 테스트 9건: 요청 검증, 입력 차단, 출력 차단, 안전 검사 실패, 잘못된 JSON, 언어별 거절 응답.
- 표현집 중복 저장·잘못된 데이터·삭제·손상된 저장소 처리 검증 통과.
- 브라우저에서 영어·일본어·중국어 화면 전환 및 재시작 후 설정 저장 확인. 한국어 기본 화면 확인.
- 실제 DeepSeek 안전 검사 품질, TestFlight 배포, App Store Connect 공개 항목은 별도 검증 필요.

## 운영 및 제출 전 확인
1. 원격 서버에 safety-i18n-v1 리비전이 배포되었는지 확인. 앱 설치만으로 서버가 바뀌지는 않음.
2. DeepSeek API 계약의 데이터 보관 기간·처리 지역·학습 제외 조건 확인. 공개 일반 정책은 개발자 하위 앱 처리 규칙을 직접 보장하지 않음. 이 조건을 확인하기 전 개인정보 검토 완료로 판단하지 말 것.
3. 개인정보 정책 및 지원 페이지의 공개 URL과 App Privacy 답변을 실제 운영 조건에 맞춤. 번들 HTML 경로는 App Store Connect 공개 URL로 사용할 수 없음.
4. 18세 이용 조건과 실제 콘텐츠에 맞게 최신 연령 설문 작성. 체크박스는 이용자 자기 확인이며 신원 기반 연령 검증은 아님.
5. 유해 요청·우회 프롬프트·자해 위기 지원을 실제 운영 API에서 여러 언어로 평가. 신고 이메일 모니터링과 처리 절차 마련.
6. 안전 검사는 API 비용과 응답 지연을 늘림. 실제 성능·쿼터·운영 잔액 확인. RATE_LIMIT_KV 미설정 또는 오류 시 기존 제한 해제 동작이 남아 있으므로 운영 설정 확인.
7. iPhone/iPad에서 키보드·회전·알림·신고·백업 내보내기 및 복원을 확인. iOS 파일 내보내기의 실제 저장 성공은 별도 확인 필요.
8. 심사 노트에는 로그인·결제·사용자 간 채팅 없음, 언어 선택 위치, AI 표시·신고·동의 철회·삭제·표현 복습 경로를 설명.
