# SweetTalk

## Short description
친구처럼 대화하며 자연스럽게 언어를 연습하는 AI 대화 앱

## Full description
SweetTalk은 설정한 캐릭터와 친구처럼 대화하며 외국어 표현을 연습할 수 있는 AI 대화 앱입니다.

- 친구·대화 상대의 이름, 성격, 말투, 관심사 설정
- 한국어·영어·일본어·중국어 간체 지원
- 메시지별 번역과 다른 표현 확인
- 위치와 날씨를 반영한 자연스러운 대화
- 대화와 캐릭터를 기기에 저장하고 백업·복원

AI 응답은 자동 생성되며 실제 사람이나 전문 상담 서비스를 대체하지 않습니다.
