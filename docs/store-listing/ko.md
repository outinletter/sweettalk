# SweetTalk

## 설명
가상의 성인 AI 연인과 대화하면서 다양한 표현을 연습하세요. 만 18세 이상 이용자를 위한 앱입니다.

- 첫 화면 환경설정에서 한국어·영어·일본어·중국어 간체 선택
- 선택한 언어로 화면과 새로운 AI 대화 표시
- 영어 선택 시 한국어 번역, 나머지 언어 선택 시 영어 번역 및 대체 표현 1가지
- 성인 캐릭터의 이름·성격·말투·관심사 설정
- 기기에 저장되는 대화 기록과 백업·복원
- 별도로 선택한 경우에만 지역·날씨 맥락 활용
- 선택적 로컬 안부 알림, AI 응답 신고 및 데이터 삭제

AI는 가상의 캐릭터이며 실제 사람·상담·응급 서비스를 대체하지 않습니다. 응답·번역·안전 검사를 위해 명시적 동의 후 외부 AI 서비스에 데이터를 전송합니다. 안전 검사 실패 시 응답이 제공되지 않을 수 있습니다. 기존 대화는 언어 변경 후에도 원문을 유지합니다.
