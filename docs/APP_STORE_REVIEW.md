# SweetTalk App Store 감수 결과

2026-10-14, Apple App Review Guidelines 기준 소스 검토.

## 보완
- 앱 번들에 개인정보 처리방침과 약관을 포함하고 동의 화면·설정에서 연결.
- Cloudflare / DeepSeek / wttr.in 데이터 흐름, 저장·삭제·백업 및 문의 경로 명시.
- 약관을 실제 성인 캐릭터의 비노골적 연인형 대화 동작과 일치시킴.
- AI 응답 표시 및 이메일 앱을 통한 신고 작성 경로 추가. 자동 발송하지 않으며 대화 내용도 자동 첨부하지 않음.
- 서버에서 중복 system 역할과 잘못된 역할 거부, 전달 속성 제한, 모델 고정 및 생성 매개변수 범위 제한. 내부 오류 정보 노출 축소.
- iOS Local Notifications Swift Package 연결 복구.
- 앱 PrivacyInfo.xcprivacy를 리소스에 연결하고 콘텐츠·입력 위치·IP 관련 선언 추가. SDK 자체 매니페스트는 의존성에서 제공.

## 검증
- TypeScript 및 Vite 프로덕션 빌드 통과.
- API 모의 검증 4건 통과: 잘못된 역할, 중복 system, 긴 메시지 거부 / 정상 요청·안전 지침·모델 및 토큰 제한 확인.
- plist와 Xcode 프로젝트 파일 문법 검사 통과.
- Xcode Debug iOS Simulator 빌드 통과(arm64 / x86_64, 서명 없음). 실행·기기 동작 검증은 미실시.
- 원본 폴더에는 node_modules가 없으므로 npm ci 후 npm run cap:sync를 실행하여 로컬 플러그인 의존성을 설치하고 재동기화할 것.
- 실제 기기 UI, 알림 수신, 실제 AI 서비스의 유해 응답 방지 검증은 수행하지 않음. 서버 지침은 모델의 안전성을 보장하지 않음.

## 제출 전 남은 확인
1. Cloudflare에 수정된 서버와 웹 자산을 배포해야 실제 서비스에 적용됨. 이 작업에서 배포하지 않음.
2. 실제 입력·출력 콘텐츠 필터와 신고 처리 운영을 검증할 것. 현재 모델 지침과 이메일 신고만으로 악성 프롬프트에 대한 필터링을 보장할 수 없음.
3. App Store Connect의 공개 개인정보 URL에 이번 정책을 게시하고 공개 URL 접근 확인. 번들 내부 경로는 스토어 공개 URL로 사용할 수 없음.
4. App Privacy 답변을 DeepSeek/Cloudflare의 실제 보관, 학습 이용 및 사용자 식별 조건과 대조. 콘텐츠, 수동 입력 위치, IP를 누락하지 말 것. 새 매니페스트는 보수적으로 연결됨으로 선언했으며 운영 조건에 따라 재확인 필요.
5. 앱 내 14세 이용 기준은 Apple의 연령 등급이 아님. 실제 콘텐츠와 최신 연령 설문에 맞춰 제출 등급을 지정하고 미성년자 개인정보 처리 조건을 확인.
6. API 키·사용량 제한 KV·운영 문의 이메일 확인. KV 미설정·오류 시 사용량 제한이 해제되는 기존 동작이 있어 운영 설정 필요.
7. 리뷰 노트에 로그인·결제·사용자 간 채팅 없음, 영어 번역, 로컬 저장, 선택적 알림, 동의·삭제·신고 경로를 설명. 실제 iPhone/iPad에서 약관 표시, 이메일 신고, 동의 철회, 알림과 백업을 확인.
8. 웹뷰 앱의 기능성(4.2)과 차별성(4.3)은 심사 판단 사항. 현재 번역·캐릭터 설정·로컬 기록·알림의 효용을 실제 스크린샷과 설명에 반영.

승인을 보장하지 않으며 위 운영·기기 검증이 끝나기 전 제출 준비 완료로 판단하지 않음.

공식 기준: https://developer.apple.com/app-store/review/guidelines/
