# SweetTalk

通过已保存的表达回忆原文、写新句子并对照复习。支持咖啡店点单、周末邀约情景提示，也可请求修改句子并解释原因。卡片仅填入输入框，由您决定何时发送。复习为自行检查，并非自动评分。

适用于18岁及以上用户的虚构成年AI伴侣及语言练习应用。

在首页设置中选择简体中文、韩语、英语或日语。界面和新AI回复使用所选语言。选择英语时提供韩语翻译，其他语言提供英语翻译及一种替代表达。支持成年角色设置、本地记录、备份恢复、可选天气和本地提醒、回复举报及数据删除。

AI是虚构角色，不能代替真实关系或专业建议。生成、翻译和安全检查需要明确同意后将数据发送至外部AI服务。安全检查失败时可能不提供回复。既有记录保留原始语言。
