# 심사 감수 후 개선

- 채팅 상단 ‘연습’으로 진입: 번역을 보고 원문 떠올리기, 새 문장 작성, 원문 비교, 이번 세션 복습 수, 작성 문장을 대화 입력창에 옮기기. 자동 채점 또는 지속적인 학습 진도 기록은 제공하지 않는다.
- 카페 주문·주말 약속·이전 문장 교정 이유 요청 카드. 카드는 입력창만 채우며 사용자가 전송한다. 문장 교정은 AI 요청이므로 정확성을 보장하지 않는다.
- 연습 UI 한국어/영어/일본어/중국어 지원. 기존 기록의 언어는 그대로 보존.
- 시작 안내에서 번역 방향과 저장 표현 복습을 설명. 기존 ‘2가지’ 키는 번역 함수가 이미 1가지로 표시하고 있었으므로 이전 감수의 불일치 판단은 정정한다.
- 메시지 신고에 대상 응답을 편집 가능한 상태로 표시. 이메일 전송은 사용자가 직접 수행. 현재 화면에서 응답 숨김/다시 표시 제공. 숨김은 기록 삭제나 영구 차단이 아니며 재진입 시 해제된다.
- Capacitor Filesystem/Share로 iOS 백업 공유. 임시 캐시 파일은 공유 완료/실패 후 삭제. 파일 저장을 사용자가 확인한 경우만 백업 시각 갱신. 웹 다운로드 URL은 즉시 해제하지 않음.
- Filesystem 파일 타임스탬프 API 사유 C617.1을 앱 개인정보 매니페스트에 추가.
- 서버는 생성에 쓰는 전체 대화 맥락의 안전 검사를 수행. 사용량 제한 저장소 미설정/실패 시 AI 호출을 중단. Cloudflare KV 카운터는 원자적·강한 제한을 보장하지 않으므로 고부하 악용 대응은 별도 운영 보완 필요.
- Capacitor core/ios/android/cli 8.5.1 적용: GHSA-rvm3-566m-v7fv 대응. 전체 개발 도구 의존성의 모든 취약점을 해소했다는 의미는 아니다.

## 검증

- TypeScript, Vite 배포 빌드, 표현집 검증 통과.
- 서버 모의 테스트 12개: 입력 검증, 입출력 차단, 오류 차단, 다회차 맥락 포함, 사용량 보호 실패 시 호출 중단.
- 백업 모의 테스트: 네이티브 공유 성공, 공유 취소 시 임시 파일 정리, 파일 작성 실패 시 공유 중단, 웹 파일 공유 경로 통과.
- Capacitor 8.5.1 iOS 서명 빌드 통과. 빌드 앱의 웹 자산과 최종 배포 빌드 일치 확인, 개인정보 매니페스트 포함 확인.
- 실제 AI 안전성 평가는 수행하지 않았으며 모의 테스트가 이를 대신하지 않는다.
- 브라우저 검증은 페이지 로드/CDP 시간 초과로 완료하지 못함. 아이폰의 공유 시트 저장·취소·복원과 VoiceOver/큰 글자 QA도 최종 사용자 검증 필요.

## 제출 전 남은 외부 항목

1. Cloudflare 기존 OAuth 인증은 401. 운영 API에는 새 리비전 헤더가 없어 수정 서버의 운영 반영 미확인. main 푸시는 운영 배포 성공을 의미하지 않는다. 운영 프로젝트의 production branch=main 및 API secret/KV를 확인하고 배포 후 정상 생성·번역·차단 시험 필요.
2. DeepSeek API 보관·처리 지역·학습 이용 조건, 삭제 협조 절차는 운영자가 계약에 근거해 확인. 확인 전 보장 문구를 추가하지 않았다.
3. 실제 개인정보 처리에 맞게 App Store Connect 공개 URL·App Privacy·연령 설문·스크린샷 갱신. 기존 스크린샷은 새 연습 화면을 담지 않는다.
4. 신고 응답 기한 및 운영 담당자 확정, 다국어 유해 콘텐츠/다회차 우회 시험. 아이콘·폰트·상표 권리 확인.
